# 🧠 Metataidot – The Hidden Strength Behind Workplace Success

**An interactive HR presentation exploring the importance of metaskills in modern working life.**

*Metataidot – työpaikan piilotettu helmi*

## 📖 About the Project

What makes someone capable of learning new skills, adapting to change, collaborating effectively, and solving unfamiliar problems?

The answer often lies in **metaskills (metataidot)** — transferable capabilities that help people develop and apply other skills.

This project explores how metaskills contribute to professional development, workplace performance, and adaptability in a constantly changing working environment.

It combines three areas of interest:

- 🧑‍💼 **Human Resources:** Employee development, competencies, and workplace learning.
- 🎨 **Visual Storytelling:** Engaging presentation design and animated transitions.
- 🐍 **Python Development:** Making educational content accessible through an interactive Streamlit application.

The presentation is written in Finnish, while this documentation is provided in English for a broader audience.

---

## 💡 What Are Metaskills?

Metaskills are capabilities that support the acquisition, development, and effective use of other skills.

Unlike job-specific competencies, they can be applied across different professions, industries, and situations.

The presentation introduces seven important metaskills:

| Metaskill | Finnish | Workplace Relevance |
|---|---|---|
| Adaptability | Sopeutumiskyky | Responding effectively to change |
| Critical Thinking | Kriittinen ajattelu | Evaluating information and making informed decisions |
| Communication | Vuorovaikutustaidot | Sharing ideas and understanding others |
| Collaboration | Yhteistyötaidot | Working effectively with different people |
| Creativity | Luovuus | Discovering new approaches and solutions |
| Self-Awareness | Itsetuntemus | Understanding personal strengths and development needs |
| Learning Agility | Oppimiskyky | Learning and applying new knowledge |

## 🎯 Why Metaskills Matter in HR

Metaskills are relevant throughout the employee lifecycle, especially in:

- **Recruitment:** Recognizing transferable skills and learning potential.
- **Onboarding:** Helping employees adapt to unfamiliar working environments.
- **Learning & Development:** Supporting continuous professional growth.
- **Employee Experience:** Encouraging communication, cooperation, and self-awareness.
- **Organizational Development:** Building teams that can navigate change.

The purpose of this project is to demonstrate how these concepts can be communicated through accessible and engaging visual content.

## 🚀 Project Features

### 🎨 Animated PowerPoint Presentation

The original presentation was developed using Microsoft PowerPoint and includes:

- Morph-based slide transitions.
- Futuristic blue and purple visual design.
- Visual diagrams illustrating key metaskills.
- Educational examples and practical HR applications.

### 🐍 Interactive Streamlit Application

A Python-based viewer makes the presentation accessible through a web browser.

Features include:

- Navigation between eight presentation slides.
- Browser-based viewing without requiring PowerPoint.
- Access to the original PowerPoint presentation.
- Optional video playback for showcasing the original animations.

**Note:** Streamlit displays exported slide images rather than executing native PowerPoint Morph animations. The original animation experience is available through the PowerPoint file or an exported video.

## 💻 Run the Application Locally

**1. Clone or download this repository.**

**2. Install the required dependencies:**

```bash
pip install -r requirements.txt
```

**3. Start the Streamlit application:**

```bash
streamlit run app.py
```

**4. Open the local URL displayed in your terminal.**

Your Metataidot presentation should now be accessible in your browser.

## 🌐 Online Deployment

The application can be published using [Streamlit Community Cloud](https://share.streamlit.io/).

To deploy it:

1. Connect your GitHub account to Streamlit.
2. Select this repository.
3. Choose `main` as the branch.
4. Set `app.py` as the main application file.
5. Deploy the application.

Once deployed, the presentation can be shared through a public URL.
